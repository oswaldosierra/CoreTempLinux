# Código de conducta

## Nuestro compromiso

Como miembros, colaboradores y responsables de este proyecto, nos comprometemos a
hacer de la participación una experiencia libre de acoso para todo el mundo, con
independencia de edad, identidad de género, nivel de experiencia, nacionalidad,
apariencia, etnia o religión.

## Comportamiento esperado

- Usar un lenguaje acogedor e inclusivo.
- Respetar los distintos puntos de vista y experiencias.
- Aceptar con cortesía la crítica constructiva.
- Priorizar lo mejor para la comunidad.

## Comportamiento inaceptable

- Lenguaje o imágenes sexualizadas y atención sexual no deseada.
- Comentarios insultantes o despectivos y ataques personales o políticos.
- Acoso público o privado.
- Publicar información privada de terceros sin permiso.

## Aplicación

Las conductas abusivas pueden reportarse abriendo un *issue* privado o
contactando con el mantenedor del proyecto. Todas las quejas se revisarán e
investigarán de forma justa.

Este código de conducta se adapta del [Contributor Covenant](https://www.contributor-covenant.org),
versión 2.1.
